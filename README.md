# 🎬 Locadora Ghibli

Uma aplicação web interativa desenvolvida em **React**, inspirada no universo mágico dos filmes do Studio Ghibli. O projeto simula o catálogo e o sistema de aluguel de clássicos animados, permitindo navegar por títulos, filtrar conteúdos e explorar detalhes de cada obra.

## 🤖 Tecnologias Utilizadas

Este projeto foi desenvolvido utilizando as seguintes tecnologias e ferramentas:

* **React** (com componentes e manipulação de estado)
* **Vite** (para empacotamento rápido e otimização)
* **JavaScript (ES6+)**
* **HTML5 e CSS3**
* **Git e GitHub** (Versionamento e Deploy)

## ✨ Funcionalidades

* 🔍 **Busca de Filmes:** Encontre rapidamente seus títulos favoritos através da barra de pesquisa.
* 🏷️ **Filtros por Categoria:** Navegue facilmente entre as opções disponíveis no catálogo.
* 📖 **Detalhes dos Filmes:** Visualize sinopses, capas e informações completas de cada obra.
* 🛒 **Sistema de Aluguel (Simulação):** Interface interativa voltada para a experiência de uma locadora tradicional.
